One-time setup helper

Generate your config.js

This avoids editing code manually. Create your Supabase project, run supabase_schema.sql, then paste the two values below.

Use the Project URL and anon public key from Supabase Project Settings → API. Never put the service-role key in this website.
After download:
1. Replace assets/js/config.js with the downloaded file.
2. Push/upload the updated file to GitHub.
3. Cloudflare Pages will redeploy automatically.
4. Open /admin.html, sign in, and click Save & Publish once to initialize the live content.
