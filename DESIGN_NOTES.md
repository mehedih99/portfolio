# Portfolio presentation update

The public portfolio now uses a cream, forest-green and gold editorial design inspired by the supplied hospitality portfolio reference. Existing career facts, original photographs, CMS fields and the PDF route are retained. The management approach and UAE/Germany presentation sections introduce the existing experience without adding invented results, language proficiency or work authorization claims.

English, German and Arabic are available through the header selector. Arabic uses a right-to-left layout; language and colour preferences persist in the visitor's browser. Translations cover the interface and existing source copy. They match source text rather than replacing database content: new or edited CMS text remains in its original language until a matching translation is added to `assets/js/records-locales.js`. Company names, document images, historical PDF content and product names remain original. Site language does not imply spoken proficiency.

The Supabase configuration, content loader, data schema, admin application and built-in content are unchanged. No database or storage write is needed to use this design. The current Supabase project can remain in its existing account.

Validation: JavaScript syntax and whitespace checks; browser review of English/German/Arabic; live Supabase content and profile image loading; responsive layout, menu, colour mode and image preview checks. No authenticated CMS write was performed. Fonts fall back to installed serif and sans-serif faces when Google Fonts is unavailable.
